Entry for the [One Emoji, One Smile](https://make.fun/competitions/u-0xkianno-one-emoji-one-smile-5470751f) bounty on make.fun: exactly one emoji, the one most likely to make a stranger smile.

`main.py` writes a single emoji — 🥹 (U+1F979, face holding back tears) — to `/output/entry.txt`: warm and touched at first glance, universal with no irony or in-joke, chosen rather than the default smiley, and right for a stranger.
